# Do AI judges see what an editor sees?

A small study of the two automatic judges in Tev, an AI video editor for short talking-head films: a rule-based
scorer and an LLM critic. Each is compared with a video editor's own judgments, one editing decision at a time
(zooms, titles, pictures over the talk), and with flaws planted on purpose in copies of edited films.

**Status, 10 November 2026:** the protocol is being written. This repository stays private until the protocol is
frozen, before any judge runs.

**What will be here:** `PROTOCOL.md`, written before any judge runs; the analysis code; anonymised results tables;
the chart; the write-up.

**What stays private:** the films, the footage, the prompts, and Tev's own code.
